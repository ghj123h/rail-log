# 车站站台范围

车站使用覆盖同站各车场站台区域的定向矩形。存在 OSM 站台面时保留其范围；只有站台中心线时补估宽度；缺少站台几何但有到发线时，结合股道连通关系、公开尺寸资料及明示默认值估计。到发线包含咽喉，不将其全长作为站台长度。不同车场及设计版本的资料分别保留。

矩形采用白色填充和朱红色边框，覆盖框内轨迹是预期显示效果。石家庄站名的文字右缘固定在原车站锚点左侧18像素，不随矩形放大而增加偏移；其他站名继续按矩形范围留出间距。

既无可用站台面/中心线、也无到发线几何时，保留原始圆点和原有定位规则。当前包括任丘西、寿县、衡水南、颍上北；广安门、永乐继续保留命名圆点。公开车站节点投影不能单独证明完整站台范围。合肥南、淮安东有到发线，但各股道连接中点差异较大，矩形中心仍为较低置信的节点投影近似。

缺少公开长度时暂取450米，缺少平台宽度时暂取12米；从外侧股道推台边时另留2米。这些是地图估算参数，不代表实测尺寸。已有站台几何不会被默认长度裁短。矩形的屏幕长边最小16像素、短边最小8像素，分别与各自按地图比例计算的尺寸取较大值，不锁定长宽比，避免细长小站因短边下限被整体放大。最小长度为最小宽度的两倍，短边仍大于圆点的6.8像素直径。矩形的地理中心、方向和数据角点保持不变；缩小地图时显示尺寸不代表真实地图比例。无矩形的圆点继续使用半径3.4像素。

网页矩形的左右边界距离最外侧到发线至少20米，同时包住原始或推算的全部站台范围。20米以到发线中心线为基准，按地理距离计算；纵向仍采用站台原有长度，不给矩形四边统一外扩。只取站台纵向范围内的到发线片段，避免咽喉、整条铁路或无关站场撑大范围。到发线依据连通拓扑和站台临接关系识别，不仅依赖 `service=siding` 标签；临台客运股道即使标记为 `usage=main` 也纳入。缺少可用到发线、但有站台几何时保留原站台包络，不凭空加20米。

2026-10-27审核的75个矩形中74站具备上述到发线依据；凤台南的站台区仅有中央正线几何，未据此宣称已核验到发线20米净距，继续保留原台面包络。沧州西按3至6道在站台长度内的横向极值重制，显示范围约449.62×88.91米；原台面约449.62×42.54米，纵向不变。

徐州东分别处理京沪场与徐兰场：保留已绘的7个京沪场国铁台面，排除属于地铁站点关系的地下台面 `1455925727`；徐兰场缺少台面几何，使用已核验的17至22、25至29道到发线辅助补估站台范围，缺少公开尺寸时保留450米长度、12米平台宽度的默认来源标记。显示矩形覆盖两场并按最外到发线留足20米，不将已有部分台面误当作全站完整范围。

审核后的 WGS84 几何及逐站来源保存在 `tools/station_footprints.json`。`platformCorners` 与 `platformLengthM/platformWidthM` 保留原始/推算站台范围；`arrivalTracks` 保存已识别到发线在站台长度内的裁剪片段、OSM对象及识别依据；`corners` 与 `lengthM/widthM` 是最终显示包络。`tools/build_route_maps.py` 依这些原始角点、到发线及 `arrivalClearanceM` 生成各记录的 `stations[].platform.corners`。允许左右补足量不同，显示框几何中心可相应偏移；原车站标签锚点及圆点车站坐标保持原值。站台范围不改变实测轨迹、速度采样或用户标记时刻。

## 来源与许可

2026-11-05 新增北京北、清河、沙河、昌平、八达岭长城五站范围，现共80个矩形，既有75个矩形与6处圆点决定保留。北京北接受6条国铁站台线，清河4条，沙河1条；线状几何采用12米默认宽度补估，并保留已有顶点与纵向范围。北京北的550米台长依据北京市重点站区管理委员会资料；清河、沙河无独立长度确认时采用450米下限，较长的映射几何不裁短。昌平、八达岭长城各保留2个站台面，不用默认尺寸替代。

新站到发线逐条按临台关系核查。昌平仅采用4/6、III/5临台线，排除非临台正线和外侧货运、安全及咽喉线；沙河仅取映射侧式站台旁4道；八达岭长城取地下3、4道，排除旧京包线及缆车。清河及北京北排除地铁站台和轨道。最终横界仍按最外临台到发线至少20米、纵长不扩的规则生成。逐对象OSM链接、资料、估算字段及筛选依据保存在 `tools/station_footprints.json` 中各站条目。

本次S206（`261105164159`）依记录者明确指示豁免站台范围校验，保留八达岭、青龙桥、三堡、居庸关、东园、南口的原圆点。此项是单次记录例外，保存于 `recordExceptions`，不构成其他运转或普速铁路的通用豁免。

铁路和站台几何来自 OpenStreetMap，OpenRailwayMap 展示相同来源的铁路数据。本次使用2026-10-27下载的 OSM 公开站区数据；逐站记录保留原始对象 ID、公开尺寸资料链接、估算方法及默认字段。不能把已收集的 OSM 图形数量直接视为完整实体台数。
